Break it moves the cut corner onto .flip-card-inner — the element carrying preserve-3d. That silently flattens the 3D context: the card stops flipping and renders the front, mirrored. getComputedStyle still reports preserve-3d, which is what makes it expensive to debug.

Hover is offered so it can be felt, not because it's advisable: in a card grid the pointer crossing the page flips everything it passes, and it does nothing at all on touch. The card book has click bound already (expand, or pick in Select mode), so a real flip wants its own affordance.
